# 100-company smoke result

A complete one-command run of the pushed code over 100 organisation numbers drawn from the full
411,160-company universe and **not** in `entry-companies.jsonl` (plus company 811413682, Elopak, which
Builderr used as its evidence-complete example). Produced from a clean clone with:

```bash
python scripts/run_agent.py --organisations out/smoke-100/input-organisations.jsonl \
  --bulk brreg-enheter.csv --output-dir out/smoke-100-rerun --run-id clean-100 --expected-count 100
```

| | |
|---|---|
| terminal results | 100 for 100 inputs, all unique, none failed |
| claims | 2,110 |
| wall clock | 17m30s (`wall-clock.txt`) |
| outbound requests | about 1,010 (registry 722, key-free site probe 75, site crawl 122, about 87 annual-report downloads) |
| evidence audit | `audit-report.json`: every one of 1,923 available claims has a public source URL, retrieval time, SHA-256 and supporting text; 1,759 verify completely from `envelopes.jsonl` alone (inline `source_snapshots`: body hash and exact excerpt); the other 164 rest on annual-report PDFs, carried by hash/size/path |

`envelopes.jsonl` is one JSON object per line. `viewer.html` opens offline. The raw saved bodies
(`snapshots/`) are regenerated by the run and are not committed, because the result already carries the
text bodies inline and the PDFs are public at each evidence `source_url`.
